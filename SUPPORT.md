# Support

Read [Applying](docs/applying.md), [Diffing](docs/diffing.md), or
[Pointers](docs/pointers.md) for the relevant operation.
For help, open an [issue](https://github.com/altophp/json-patch/issues) with PHP and
package versions, minimal input and patch, diff options, expected result, and
actual exception or output. Preserve the distinction between lists and object-like
arrays, and remove secrets or private document data before sharing.
